Codeur - agent IA de codage local, hors ligne
=============================================

Contenu de ce dossier :
  - Codeur.exe  : l'agent pret a l'emploi (double-clic pour demarrer)

Premier lancement sur un poste (Internet requis une seule fois) :
  Codeur.exe installe tout seul, sans droits administrateur :
    1. Ollama (moteur IA local)  ~1,6 Go de telechargement
    2. Le modele qwen2.5      ~2 Go de telechargement
    3. Le modele de VISION llava:7b  ~4,7 Go (lecture des images/captures)
       -> sauter cette etape : variable CODEUR_NO_VISION=1
    4. Il cree une icone "Codeur" sur le bureau
  Suivez la progression dans la fenetre noire qui s'ouvre.
  La vision sert a LIRE les images (captures d'ecran, QCM, photos de
  documents). Sans elle, l'agent refuse honnetement de decrire une image.

Lancements suivants :
  Double-cliquez sur l'icone "Codeur" du bureau : l'agent demarre
  comme une application normale (plus de telechargement, plus de setup).
  Le chat s'affiche dans le navigateur (http://127.0.0.1:3000).

Hors ligne :
  Une fois le modele charge, l'agent fonctionne 100 % hors ligne :
  aucun acces Internet, tout se passe sur le poste.
  Fermez la fenetre noire pour arreter l'agent.

Pieces jointes (fichiers et images) :
  Dans le chat web, le bouton 📎 (ou glisser-deposer, ou copier-coller
  d'une capture d'ecran avec Ctrl+V) permet d'envoyer un fichier ou une
  image avec votre question (max 8 fichiers de 8 Mo).
  Les documents (PDF, Word, Excel, PowerPoint, texte, code) sont lus
  automatiquement. Les IMAGES (captures d'ecran, photos) sont decrites par
  le modele de vision llava:7b installe au premier lancement, ou par l'OCR
  Tesseract s'il est installe. Si aucun des deux n'est disponible, l'agent
  le dit honnetement et ne devine jamais le contenu.

Generation d'images (outil generer_image) :
  L'agent peut creer des images. Trois moteurs possibles, dans l'ordre :
    1. Stable Diffusion deja lance sur le poste (ComfyUI, Automatic1111...)
       -> variable AGENT_SD_URL=http://127.0.0.1:7860
    2. stable-diffusion.cpp avec un modele -> AGENT_SDCPP=chemin\sd-cli.exe
       et AGENT_SD_MODEL=chemin\modele.safetensors
    3. Sinon : ILLUSTRATIONS locales generees sur le poste (graphiques en
       barres ou en secteurs, organigrammes, mind-maps, tableaux de
       comparaison, formules) - disponibles toujours, meme sans Internet.
  L'agent est honnete : il dit toujours quel moteur a produit l'image et ne
  simule jamais une photo realiste quand seul un schema a ete cree.

PowerPoint de cours (outil creer_powerpoint) :
  L'agent cree des presentations .pptx pour enseignants : titres, puces,
  notes, IMAGES (celles du dossier ou generees par generer_image) et LIENS
  VIDEO cliquables. Exemple de demande :
    "Cree un PowerPoint de cours sur les integrales : une diapo d'objectifs,
     une diapo avec l'exemple ln(x+1), et ajoute un lien vers la video
     https://www.youtube.com/watch?v=..."
  Les fichiers .pptx sont crees dans le dossier presentations/ de l'espace
  de travail.

Premiere fois sur un poste de l'ecole :
  - Windows SmartScreen peut afficher "programme non reconnu" :
    cliquez sur "Plus d'informations" puis "Executer quand meme".
    (Normal : logiciel non signe.)
  - Windows Pare-feu peut demander l'autorisation pour Ollama :
    autorisez (il n'ecoute que sur le poste, adresse 127.0.0.1).

Pre-requis materiel : Windows 10/11, 8 Go de RAM minimum,
plus environ 8 Go libres sur le disque.
